## Key Notes

- **Race pace (4:44 /km)** should feel controlled in weeks 3–6. By weeks 8–10 it should feel sustainable. If it still feels like a sprint, hold 4:50 and build.
- **Long runs are easy.** You were running long runs at 5:29–5:34 in April. Slow down to 5:50–6:00 — the aerobic adaptation still happens and you recover faster.
- **HR caps:** Easy < 155 bpm. Long run 150–165 bpm. Tempo 170–180 bpm. Intervals → controlled discomfort, not all-out.
- **Makeup runs:** If you miss a session, Percy will automatically credit it within 7 days if you run on a free day.
- **Do not add sessions.** The plan is 4 days/week deliberately. Resist the urge to run on rest days in peak weeks.
